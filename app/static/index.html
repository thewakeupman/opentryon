没有显卡？试试官方在线演示

在 .env 中设置 VTON_PROVIDER=space 后重启。每次上传须明确同意。公共服务有额度限制，仅提供模型自身的人物保持能力，不含额外的像素保护合成。

本地 FASHN 模型

安装推理环境和模型权重后，重启服务。建议使用显存充足的 NVIDIA 显卡；CPU 推理会慢得多。

pip install -e ".[inference]"
python scripts/download_weights.py
python -m uvicorn app.main:app --port 8000

已有 GPU 服务器？

在 GPU 服务器上部署本工具箱和本地模型，再在这台电脑的 .env 中配置以下内容并重启：

VTON_PROVIDER=remote
VTON_REMOTE_URL=https://your-gpu-server
VTON_REMOTE_API_KEY=your-worker-key

首次生成时需要加载模型。效果会受姿态、光线和服装复杂度影响。GPU、Docker 配置和依赖许可详见 README.zh-CN.md。
